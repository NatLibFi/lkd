# BFFI datamodel
The BFFI datamodel is a Finnish adaptation of the linked bibliographic datamodel BIBFRAME by the Library of Congress. It was originally produced by the Linked library data project (LKD) coordinated by the National Library of Finland in 2022-2024, and continues to be actively maintained and developed beyond the project.  

- Project homepage <https://www.kiwi.fi/display/LKD>

## About the BFFI data model

The BFFI data model is based on the BIBFRAME data model published by the Library of Congress. The BFFI model has been supplemented with categories and properties from RDA Registry, as well as additions based on the Finnish description guidelines. A notable difference to the Library of Congress BIBFRAME data model is that the BFFI data model splits bf:Work into disjoint classes bffi:Work and bffi:Expression corresponding to the structure of RDA classes.

- Namespace of the model <http://urn.fi/URN:NBN:fi:schema:bffi:>
- Preferred prefix "**bffi**".
- [Data model documentation](https://github.com/NatLibFi/lkd/wiki) (in LKD wiki, work in progress)

## Current Version

Version 1.1.0, published on 2026-11-13, updates the BFFI to comply with BIBFRAME 3.0 as well as some fixes to labels, mappings, and definitions. For a full change log, see [CHANGELOG.md](CHANGELOG.md).

### Old Versions

Version 1.0.0, published on 2025-01-02, includes all the BIBFRAME classes and properties required in Finnish cataloguing.
